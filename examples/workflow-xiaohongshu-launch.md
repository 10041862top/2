# 多智能體工作流：小紅書品牌推廣

> 從 0 到 1 用多個智能體配合完成一次小紅書品牌種草推廣。

## 場景

你是一個新消費品牌，準備在小紅書上做第一波種草推廣。預算有限，需要 2 周內完成從策略到執行到復盤的全流程。

## 智能體團隊

| 智能體 | 在這個流程中的角色 |
|--------|-------------------|
| 小紅書運營 | 制定內容策略和達人合作方案 |
| 品牌守護者 | 確保品牌調性一致 |
| 內容創作者 | 產出種草筆記內容 |
| 數據分析師 | 追蹤投放數據、出復盤報告 |
| 增長黑客 | 設計裂變和轉化路徑 |

## 工作流

### 第一階段：策略制定（第 1-2 天）

**第 1 步 — 激活小紅書運營**

```
激活小紅書運營。

品牌：[你的品牌名] — [一句話品牌定位]。
品類：[具體品類，比如護膚/零食/家居]。
目標人群：[年齡、城市、興趣標籤]。
預算：[總預算]，其中達人合作 [X]，信息流投放 [X]。
目標：2 周內筆記曝光 50 萬+，進店 UV 5000+。

請給出：
1. 競品在小紅書上的打法分析（找 3-5 個競品）
2. 內容方向建議（3 個主題方向）
3. 達人合作方案（KOC/KOL 配比、預算分配）
4. 兩週內容發佈排期
```

**第 2 步 — 激活品牌守護者（同步進行）**

```
激活品牌守護者。

品牌：[你的品牌名]。
品牌調性：[關鍵詞，比如"自然、真實、年輕"]。
視覺規範：[主色調、字體風格、拍攝風格]。
絕對不能出現的：[負面關鍵詞，比如"最便宜"、"絕對有效"]。

請輸出一份小紅書內容審核清單，給到後續寫內容和審達人稿件的時候用。
```

### 第二階段：內容生產（第 3-7 天）

**第 3 步 — 激活內容創作者**

```
激活內容創作者。

參考小紅書運營給出的 3 個內容方向，每個方向寫 2 篇種草筆記。

要求：
- 標題用小紅書爆款標題公式（數字+痛點+解決方案）
- 正文控制在 300-500 字，口語化，像朋友推薦
- 每篇標註建議配圖方向（幾張圖、拍什麼）
- 加上 10-15 個話題標籤

注意品牌守護者給的審核清單，不要踩紅線。
```

**第 4 步 — 激活增長黑客**

```
激活增長黑客。

在小紅書種草內容的基礎上，設計轉化路徑：
1. 筆記 → 評論區引導 → 私信/店鋪的轉化鏈路
2. 互動抽獎/打卡活動方案（提升筆記互動量）
3. 老用戶曬單返利機制

預算約 [X]，重點是用低成本撬動自然流量。
```

### 第三階段：投放和優化（第 8-12 天）

**第 5 步 — 再次激活小紅書運營**

```
內容已經發布 3 天了，以下是數據：

筆記 A：曝光 8000，點贊 120，收藏 85，評論 30
筆記 B：曝光 15000，點贊 350，收藏 200，評論 65
筆記 C：曝光 3000，點贊 20，收藏 15，評論 5
...

請分析：
1. 哪些內容跑得好，為什麼
2. 跑得差的問題在哪
3. 剩餘預算的信息流投放建議（加推哪幾篇）
4. 是否需要調整後續達人合作方向
```

### 第四階段：復盤（第 13-14 天）

**第 6 步 — 激活數據分析師**

```
激活數據分析師。

這是兩週小紅書推廣的完整數據：

總曝光：[X]
總互動（點贊+收藏+評論）：[X]
進店 UV：[X]
成交訂單：[X]
總花費：[X]

各筆記明細數據：[貼數據表]
各達人數據：[貼數據表]

請輸出復盤報告：
1. 核心指標達成情況 vs 目標
2. ROI 分析
3. 內容類型效果對比
4. 達人合作效果對比
5. 下一輪推廣的優化建議
```

## 關鍵交接點

| 從 | 到 | 交接內容 |
|----|-----|---------|
| 小紅書運營 | 內容創作者 | 內容方向、達人 brief |
| 品牌守護者 | 內容創作者 | 內容審核清單 |
| 內容創作者 | 小紅書運營 | 成稿，等審核和發佈 |
| 小紅書運營 | 數據分析師 | 投放數據 |
| 數據分析師 | 小紅書運營 | 復盤報告、優化建議 |

## 預期產出

- 6-10 篇種草筆記（含達人合作內容）
- 1 套品牌小紅書內容規範
- 1 份完整的推廣復盤報告
- 下一輪推廣的可複用 SOP
