# NEXUS 快速上手指南

> **從零到多智能體協作流水線，5 分鐘搞定。**

---

## NEXUS 是什麼？

**NEXUS**（Network of EXperts, Unified in Strategy，專家網絡統一策略）把 Agency 的 AI 專家們變成一條協調的流水線。不再是一個個激活智能體、然後祈禱它們能配合，NEXUS 明確定義了誰在什麼時候做什麼、怎麼驗證質量。

## 選擇你的模式

| 我想... | 使用 | 智能體數 | 時間 |
|--------|------|---------|------|
| 從零開始做一個完整產品 | **NEXUS-Full** | 全部 | 12-24 周 |
| 做一個功能或 MVP | **NEXUS-Sprint** | 15-25 | 2-6 周 |
| 搞一個具體任務（修 bug、搞活動、做審計） | **NEXUS-Micro** | 5-10 | 1-5 天 |

## NEXUS-Full：啟動完整項目

**複製這個提示詞來激活完整流水線：**

```
激活智能體編排者，NEXUS-Full 模式。

項目：[你的項目名稱]
需求說明：[描述你的項目或鏈接到需求文檔]

執行完整 NEXUS 流水線：
- 第 0 階段：發現（趨勢研究員、反饋分析師、UX 研究員、數據分析師、法務合規員、工具評估師）
- 第 1 階段：策略（工作室製片人、高級項目經理、Sprint 排序師、UX 架構師、品牌守護者、後端架構師、財務追蹤員）
- 第 2 階段：基礎搭建（DevOps 自動化師、前端開發者、後端架構師、UX 架構師、基礎設施運維師）
- 第 3 階段：構建（開發-測試循環 — 全部工程 + 證據收集者）
- 第 4 階段：加固（現實檢驗者、性能基準師、API 測試員、法務合規員）
- 第 5 階段：上線（增長黑客、內容創作者、全部營銷智能體、DevOps 自動化師）
- 第 6 階段：運營（數據分析師、基礎設施運維師、客服響應者、持續進行）

每個階段之間設質量門禁。所有評估必須有證據。
每個任務最多重試 3 次，超過就升級處理。
```

## NEXUS-Sprint：做一個功能或 MVP

**複製這個提示詞：**

```
激活智能體編排者，NEXUS-Sprint 模式。

功能/MVP：[描述你要做的東西]
時間線：[目標週數]
跳過第 0 階段（市場已驗證）。

Sprint 團隊：
- PM：高級項目經理、Sprint 排序師
- 設計：UX 架構師、品牌守護者
- 工程：前端開發者、後端架構師、DevOps 自動化師
- QA：證據收集者、現實檢驗者、API 測試員
- 支持：數據分析師

從第 1 階段開始，做架構和 Sprint 規劃。
所有實現任務跑開發-測試循環。
上線前必須拿到現實檢驗者的批准。
```

## NEXUS-Micro：做一個具體任務

**選你的場景，複製對應提示詞：**

### 修一個 Bug
```
激活後端架構師，調查並修復 [BUG 描述]。
修完後激活 API 測試員驗證修復。
然後激活證據收集者確認沒有視覺迴歸。
```

### 跑一個營銷活動
```
激活社交媒體策略師，擔任 [活動描述] 的活動負責人。
團隊：內容創作者、Twitter 互動官、Instagram 策展人、Reddit 社區建設者。
品牌守護者在發佈前審核所有內容。
數據分析師每日跟蹤效果。
增長黑客每週優化渠道。
```

### 做一次合規審計
```
激活法務合規員，做一次全面合規審計。
範圍：[GDPR / CCPA / HIPAA / 全部]
審計完成後，激活高管摘要生成器輸出利益相關方報告。
```

### 排查性能問題
```
激活性能基準師，診斷性能問題。
範圍：[API 響應時間 / 頁面加載 / 數據庫查詢 / 全部]
診斷完成後，激活基礎設施運維師做優化。
DevOps 自動化師部署基礎設施變更。
```

### 市場調研
```
激活趨勢研究員，做 [領域] 的市場情報收集。
交付物：競爭格局、市場規模估算、趨勢預測。
調研完成後，激活高管摘要生成器輸出簡報。
```

### UX 改進
```
激活 UX 研究員，找出 [功能/產品] 的可用性問題。
調研完成後，激活 UX 架構師設計改進方案。
前端開發者實現改動。
證據收集者驗證改進效果。
```

## 核心概念 30 秒速覽

1. **質量門禁** — 沒有基於證據的批准，階段不能推進
2. **開發-測試循環** — 每個任務做完就測；通過才繼續，不通過就重試（最多 3 次）
3. **交接** — 智能體之間結構化的上下文傳遞（不能冷啟動）
4. **現實檢驗者** — 最終質量權威；默認態度是"需要改進"
5. **智能體編排者** — 流水線控制器，管理整個流程
6. **證據高於口說** — 截圖、測試結果和數據，不是口頭聲明
