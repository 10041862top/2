# 操作手冊：多渠道營銷活動

> **模式**：NEXUS-Micro 到 NEXUS-Sprint | **時長**：2-4 周 | **智能體**：10-15

---

## 場景

你要在多個渠道同時搞一個營銷活動。內容要針對各平臺定製，品牌要一致，決策要基於數據。活動需要帶來可衡量的獲客和互動。

## 智能體陣容

### 活動核心
| 智能體 | 角色 |
|--------|------|
| 社交媒體策略師 | 活動負責人，跨平臺策略 |
| 內容創作者 | 各種格式的內容產出 |
| 增長黑客 | 獲客策略，漏斗優化 |
| 品牌守護者 | 跨渠道品牌一致性 |
| 數據分析師 | 效果追蹤和優化 |

### 平臺專家
| 智能體 | 角色 |
|--------|------|
| Twitter 互動官 | Twitter/X 活動執行 |
| TikTok 策略師 | TikTok 內容和增長 |
| Instagram 策展人 | Instagram 視覺內容 |
| Reddit 社區建設者 | Reddit 真實互動 |
| 應用商店優化師 | 應用商店（如果是移動端） |

### 支持
| 智能體 | 角色 |
|--------|------|
| 趨勢研究員 | 市場時機和趨勢對齊 |
| 實驗追蹤員 | A/B 測試活動變體 |
| 高管摘要生成器 | 活動彙報 |
| 法務合規員 | 廣告合規，信息披露要求 |

## 執行計劃

### 第 1 周：策略與內容製作

```
第 1-2 天：活動策略
├── 社交媒體策略師 → 跨平臺活動策略
│   ├── 活動目標和 KPI
│   ├── 目標受眾定義
│   ├── 平臺選擇和預算分配
│   ├── 內容日曆（4 周計劃）
│   └── 各平臺互動策略
│
├── 趨勢研究員 → 市場時機分析
│   ├── 可以蹭的熱點話題
│   ├── 競品活動分析
│   └── 最佳發佈時機
│
├── 增長黑客 → 獲客漏斗設計
│   ├── 著陸頁優化方案
│   ├── 轉化漏斗圖
│   ├── 病毒式傳播機制（推薦、分享）
│   └── 渠道預算分配
│
├── 品牌守護者 → 活動品牌規範
│   ├── 活動專用視覺規範
│   ├── 話術框架
│   ├── 活動語調
│   └── 該做和不該做的
│
└── 法務合規員 → 廣告合規審查
    ├── 信息披露要求
    ├── 各平臺廣告政策
    └── 監管約束

第 3-5 天：內容製作
├── 內容創作者 → 多格式內容製作
│   ├── 博客文章 / 長文
│   ├── 郵件序列
│   ├── 著陸頁文案
│   ├── 視頻腳本
│   └── 社交媒體文案（各平臺定製版）
│
├── Twitter 互動官 → Twitter 專屬內容
│   ├── 上線推文串（10-15 條）
│   ├── 每日互動推文
│   ├── 回覆模板
│   └── 話題標籤策略
│
├── TikTok 策略師 → TikTok 內容規劃
│   ├── 視頻方案（3-5 個視頻）
│   ├── 鉤子策略
│   ├── 熱門音頻/形式對齊
│   └── 發佈排期
│
├── Instagram 策展人 → Instagram 內容
│   ├── 信息流帖子（輪播、單圖）
│   ├── Stories 內容
│   ├── Reels 方案
│   └── 視覺風格規範
│
└── Reddit 社區建設者 → Reddit 策略
    ├── 目標 subreddit 選定
    ├── 價值優先的帖子草稿
    ├── 評論互動計劃
    └── AMA 準備（如適用）
```

### 第 2 周：發佈與激活

```
第 1 天：發佈前準備
├── 所有內容已排隊並定時
├── 數據追蹤已驗證
├── A/B 測試變體已配置
├── 著陸頁已上線並測試
└── 團隊已瞭解互動規則

第 2-3 天：發佈
├── Twitter 互動官 → 發佈推文串 + 實時互動
├── Instagram 策展人 → 發佈帖子 + Stories
├── TikTok 策略師 → 發佈視頻
├── Reddit 社區建設者 → 社區真實發帖
├── 內容創作者 → 博客發佈 + 郵件群發
├── 增長黑客 → 付費活動激活
└── 數據分析師 → 實時儀表盤監控

第 4-5 天：優化
├── 數據分析師 → 前 48 小時表現報告
├── 增長黑客 → 根據數據優化渠道
├── 實驗追蹤員 → A/B 測試早期結果
├── 社交媒體策略師 → 互動策略調整
└── 內容創作者 → 根據用戶反應做新內容
```

### 第 3-4 周：持續與優化

```
每日：
├── 各平臺智能體 → 互動和內容發佈
├── 數據分析師 → 每日表現快照
└── 增長黑客 → 漏斗優化

每週：
├── 社交媒體策略師 → 活動表現復盤
├── 實驗追蹤員 → A/B 測試結果 + 新實驗
├── 內容創作者 → 根據數據做新內容
└── 數據分析師 → 周度活動報告

活動結束時：
├── 數據分析師 → 全面活動分析
├── 增長黑客 → ROI 分析和渠道效果
├── 高管摘要生成器 → 活動高管摘要
└── 社交媒體策略師 → 經驗總結和建議
```

## 活動指標

| 指標 | 目標 | 負責人 |
|------|------|--------|
| 總觸達 | [根據預算定目標] | 社交媒體策略師 |
| 互動率 | 跨平臺平均 > 3% | 各平臺智能體 |
| 點擊率 | CTA 點擊率 > 2% | 增長黑客 |
| 轉化率 | 著陸頁轉化 > 5% | 增長黑客 |
| 獲客成本 | < [目標 CAC] | 增長黑客 |
| 品牌情感 | 正面淨值 | 品牌守護者 |
| 內容產出量 | [目標數量] | 內容創作者 |
| A/B 測試完成數 | >= 5 | 實驗追蹤員 |

## 各平臺 KPI

| 平臺 | 主要 KPI | 次要 KPI | 智能體 |
|------|---------|---------|--------|
| Twitter/X | 曝光量 + 互動率 | 粉絲增長 | Twitter 互動官 |
| TikTok | 播放量 + 完播率 | 粉絲增長 | TikTok 策略師 |
| Instagram | 觸達 + 收藏數 | 主頁訪問 | Instagram 策展人 |
| Reddit | 投票數 + 評論質量 | 引薦流量 | Reddit 社區建設者 |
| 郵件 | 打開率 + 點擊率 | 退訂率 | 內容創作者 |
| 博客 | 自然流量 + 頁面停留 | 外鏈數 | 內容創作者 |
| 付費廣告 | ROAS + CPA | 質量分數 | 增長黑客 |

## 品牌一致性檢查點

| 檢查點 | 什麼時候 | 智能體 |
|--------|---------|--------|
| 發佈前內容審核 | 每一條內容 | 品牌守護者 |
| 視覺一致性審計 | 每週 | 品牌守護者 |
| 語調檢查 | 每週 | 品牌守護者 |
| 合規審查 | 發佈前 + 每週 | 法務合規員 |
