# 第 5 階段手冊 — 上線與增長

> **時長**：2-4 周（T-7 到 T+14）| **智能體**：12 個 | **守門人**：工作室製片人 + 數據分析師

---

## 目標

協調所有渠道同時執行上市動作。上線時打出最大聲量。每個營銷智能體協同開火，工程團隊保障穩定性。

## 前提條件

- [ ] 第 4 階段質量門禁通過（現實檢驗者判定"就緒"）
- [ ] 收到第 4 階段交接包
- [ ] 生產部署方案已批准
- [ ] 營銷內容管道就緒（來自第 3 階段軌道 B）

## 質量門禁檢查清單

| # | 標準 | 證據來源 | 狀態 |
|---|------|---------|------|
| 1 | 部署成功（零停機） | DevOps 自動化師部署日誌 | |
| 2 | 系統穩定（48 小時內無 P0/P1） | 基礎設施運維師監控 | |
| 3 | 用戶獲取渠道已激活 | 數據分析師儀表盤 | |
| 4 | 反饋循環可用 | 反饋分析師報告 | |
| 5 | 利益相關方已通知 | 高管摘要生成器產出 | |
| 6 | 客服可用 | 客服響應者指標 | |
| 7 | 增長指標在追蹤 | 增長黑客渠道報告 | |

## 門禁決策

**雙籤**：工作室製片人（策略層面）+ 數據分析師（數據層面）

- **穩定**：產品已上線，系統穩定，增長渠道活躍 → 激活第 6 階段
- **緊急**：需要工程緊急響應的大問題 → 熱修復循環
- **回滾**：根本性問題 → 撤回部署，回到第 4 階段
